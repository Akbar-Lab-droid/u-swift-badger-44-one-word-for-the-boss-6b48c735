## Entry

The entry is exactly one word (up to 30 characters) that describes the boss. It lives in `entry.txt`.

## How to run

```sh
python3 main.py
```

`main.py` copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`).
